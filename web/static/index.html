Есть агенты? Дайте им сжатие

tinyimg работает как MCP-сервер: подключите его к любому AI-клиенту — и агент сможет сжимать картинки прямо в чате, без загрузок и лишних копий.

Подключение в MCP-клиенте (Claude Desktop, Cursor, Windsurf…)

{"mcpServers": {"tinyimg": {
  "url": "https://tinyimg.ru/mcp"
}}}

Или напрямую

curl -X POST https://tinyimg.ru/mcp \
  -H 'Content-Type: application/json' \
  -d '{"jsonrpc": "2.0", "id": 1,
       "method": "tools/list"}'

Удалённым клиентам нужен https. Локальный запуск работает по http.
